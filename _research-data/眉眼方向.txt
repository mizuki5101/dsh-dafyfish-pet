=== 3. 眉形真值：内端 / 外端各往哪走（★ 八字眉 vs 倒八字）===
  ★ 八字眉（委屈/担心）= 内端↑、外端↓；倒八字（生气/皱眉）= 内端↓、外端↑。
  屏幕右眉：内端=左端(x≈+73) 外端=右端(x≈+252)；屏幕左眉相反。

  ParamBrowLForm（屏幕右眉（她的左眉），眉部件 ArtMesh10）
     +1  内端 Δy=    5.7  外端 Δy=    1.1   内−外=    4.6   内高外低 → **八字**（委屈/担心）
     −1  内端 Δy=  -8.3  外端 Δy=    9.7   内−外= -18.0   内低外高 → **倒八字**（生气/皱眉）
    → 这条参数做「八字」用 +1（内−外=    4.6）

=== 4. 嘴形：左嘴角、右嘴角各往哪走 ===
  ★ 左嘴角↓ + 右嘴角↑ = 屏幕上的「撇嘴/坏笑」；反过来是镜像。

  ParamMouthX      +1  左嘴角 Δx=    4.9 Δy=  -2.7   右嘴角 Δx=    5.3 Δy=    4.2   → 左低右高（撇嘴）
  ParamMouthX      −1  左嘴角 Δx=  -5.3 Δy=    4.2   右嘴角 Δx=  -4.9 Δy=  -2.7   → 左高右低（反向撇嘴）

  ParamMouthForm   +1  左嘴角 Δx=  -6.3 Δy=    1.7   右嘴角 Δx=    6.4 Δy=    1.8   → 嘴角上翘（笑）

=== 6. 结论（抄进 manifest.json 的 _note）===
  ParamBrowLAngle/RAngle = −1：内端 ↓22.5 / 外端 ↑29.3 → **倒八字 = 生气/皱眉**（现役「生气」是对的）
  ParamBrowLAngle/RAngle = +1：内端 ↑8.5 / 外端 ↓2.8 → **八字 = 委屈/担心**（平缓版）
  ParamBrowLForm/RForm = −1：内端 ↓8.3 / 外端 ↑9.7 → **倒八字（生气）**，整体还压低 9px
  ParamBrowLForm/RForm = +1：内端 ↑5.7 / 外端 ↑1.1 → 整体抬起、内端抬更多（挑眉/可怜）
  ⚠️ 原 §十二 的「委屈 = Form ±1 + Angle −0.4」方向反了：实测是**倒八字**（更凶）。
     委屈要么 Angle +0.5（轻），要么 Form +1 + Angle +0.4（更明显），见第 5 节。
  ParamMouthX = +1：左嘴角 ↓2.7 / 右嘴角 ↑4.2、整嘴右移 5px → **撇嘴（左低右高）**
  ParamMouthX = −1：镜像（左高右低）
  ⚠️ ParamMouthX 与说话口型共用嘴：说话时建议归零，否则嘴会歪（§十二-5）。
