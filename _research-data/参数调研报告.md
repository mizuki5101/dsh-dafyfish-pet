## 1. 加载方法 (实际使用的)

Cubism Core 是 **Emscripten wasm2js 自包含构建**(内部自带 WebAssembly 垫片与 ~200KB 编译后 JS 模块,
不需要外部 _em_module.wasm, 不联网), 在 Node 里用 vm.runInThisContext() 直接求值即可,
但必须 (a) 先注入全局 __dirname/__filename/require —— 它的环境探测会走 Node 分支并在加载期解引用它们,
(b) 用 csmGetVersion() 轮询等待运行时异步就绪 (~50-70 ms), 之后才能 Moc.fromArrayBuffer。

- Core 版本: raw 83951616 = 0x05010000 -> **5.1.0**
- 不需要 window / document / WebGL; 未使用 vm sandbox 回退路径 (主路径即成功)
- 脚本: _research/cubism-loader.mjs (加载器), _research/probe-params.mjs (范围),
  _research/probe-influence.mjs (顶点影响力)

## 3. 产出文件

- D:\AI_work_space\_research\params-dump.json  —— 174 个参数的 id/min/max/default (+ canvasinfo, cdi3 无)
- D:\AI_work_space\_research\param-influence.json —— 每个参数的位移/透明/颜色影响力

测量口径: 每次测量前把**全部**参数重置为 default -> model.update() -> 快照 -> 只改一个参数 ->
model.update() -> 比较 drawables.vertexPositions。阈值 EPS = 1e-5 模型单位。
px = 模型单位 x canvasinfo.PixelsPerUnit (3326); 顶点坐标里画布宽 = 1.0 单位。
Core **不执行** physics3.json (物理是 Framework 层 cubism4.min.js 的 CubismPhysics 干的活),
所以测到的位移是 moc3 自身的变形器/glue 绑定, 不是物理模拟结果。

必须自己对 ParamEyeLOpen/ParamEyeROpen/ParamMouthOpenY 写动画。
另外 model3.json 里没有 Motions / Expressions 段 (motions 与 manifest.json 各自独立)。

    motions: {}   (空)
    expressions (14 个, 全部是"单参数 Add 1"式开关):
      口型切换 -> PARAM_EXP1=1 Add      3嘴   -> PARAM_EXP2=1 Add
      龇牙     -> PARAM_EXP3=1 Add      脸黑  -> PARAM_EXP4=1 Add
      脸红     -> PARAM_EXP5=1 Add      X X眼 -> PARAM_EXP6=1 Add
      流口水   -> PARAM_EXP7=1 Add      〇嘴  -> PARAM_EXP8=1 Add
      尾巴消失 -> Paramcol_1=1 Add      耳朵消失 -> Paramcol_2=1 Add
      水印消除 -> Paramcol_3=1 Add      微笑 -> ParamEyeSmile=1 Add
      生气     -> ParamEyeAnger=1 Add

**重要发现**: manifest.json 里的 "微笑"(ParamEyeSmile) 和 "生气"(ParamEyeAnger) 这两个表情绑定的
参数在 moc3 里**没有任何绑定**, 点了不会有任何变化 (既不动顶点也不改透明/颜色)。
assets/model/expressions/ 下另有 45 个官方 exp3.json 表情 (含"开心兴奋""生气""哭"等), 它们才是真正有效的,
manifest 里这套是另写的小开关集, 二者不要混用。

## 7. 未确定 / 需要提醒的事

1. **物理参数在浏览器里的真实作用未测**: 本次是纯 Core 测试, Core 不跑 physics3.json。
   ParamHF_* / ParamTWL* / ParamYFWL_* / ParamGSFWL* 共 122 个参数在 Core 层"无位移",
   但在实际运行时它们由 cubism4.min.js 的 CubismPhysics 从 ParamAngleX/Y/Z、ParamBodyAngleX/Y/Z 等
   驱动, 会间接带头发/裙子/饰品。所以**它们不是没用, 只是不能直接写**。
2. **px 的口径**: 位移是模型原生画布像素 (3326x4992)。桌宠窗口缩放后要按缩放比折算。
3. **"无位移"的开关类参数** 是通过 drawable 透明度/可见性实现的, 我统计了 op/vis 变化数量,
   但没有逐个人工确认视觉语义 (例如 PARAM_EXP5 影响 29 个 drawable, 具体是哪些表情件没有核对)。
4. **glue 回写**: Core 的 update() 可能把 glue 结果写回 parameters.values; 我在每次测量前全量重置,
   所以测量结果不受影响, 但**运行时要每帧重设参数值**这一点值得注意。
5. Paramcol_1 的范围是 [0,2] 而 manifest 只用到 1, 值 2 的语义未确认。
