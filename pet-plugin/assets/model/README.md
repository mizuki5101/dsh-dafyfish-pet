# 模型文件说明（大肥鱼 / dfyfish）

本仓库**不包含**大肥鱼模型本体 —— 需要你自己去作者那儿获取，然后放到这个目录里。

## 为什么要自己放

模型作者（B 站 **@Mao绒绒家园**，UID 431301506，视频 **BV1yep465EQz**）在简介里写的是：

> 这是以 DeepSeek 娘化形象为主题制作的**免费 Live2D 公皮**。
> 本作品为**非官方二创同人免费公皮，非商业使用**。
> **禁止任何形式的盗用以及出售**，此模型为无偿分享。

也就是说：**可以免费用、非商业用**；但**没有授权「二次配布」**。
把 `.moc3` 打进公开仓库就等于再分发模型本体（`.moc3` 就是模型本身，
「只不传贴图」不算规避）。所以本仓库只放**代码**和**我们自己生成的配置**，
模型的 4 个文件请你自己放进来。

## 需要哪 4 个文件

| 文件 | 从作者的哪个文件来 | 备注 |
|---|---|---|
| `dfyfish.moc3` | 模型本体 | ≈1.2 MB |
| `dfyfish.8192/texture_00.png` | 贴图 | ≈28.6 MB，8192×8192 |
| `dfyfish.physics3.json` | 物理 | ≈60 KB |
| `dfyfish.cdi3.json` | 显示信息 | ≈20 KB |

放好之后，这个目录里**应该还有这些「我们自己写的」文件**（它们在仓库里，别删）：

| 文件 | 说明 |
|---|---|
| `dfyfish.model3.json` | 我们写的 model3（原包是 VTube Studio 的，没有这个文件） |
| `manifest.json` | 我们写的表情表（17 条，参数照作者自己的 exp3 文件） |
| `rig-params.json` | 参数范围表（本项目量出来的，已随仓库提供） |

## 校验

```bash
node pet-plugin/tools/check-model.mjs
```

缺文件、尺寸不对都会直接告诉你缺哪个、放哪里。
